# 학습 자료(data) 추가 방법

화면 코드는 고치지 않고, 이 폴더의 JSON 파일만 고치면 사이트에 자료가 추가돼요.

| 파일 | 내용 |
|---|---|
| `vocabulary.json` | 단어(`items`), 헷갈리는 단어(`confusables`), 어휘 문제(`questions`) |
| `grammar.json` | 문법 문형(`items`), 문법 문제(`questions`) |
| `reading.json` | 독해 지문과 문제(`passages`) |
| `listening.json` | 청해 스크립트와 문제(`items`) |

## 모든 자료에 붙이는 출처·검수 표시

```json
"source": { "type": "ai" },
"review": "needs-review"
```

- `source.type`
  - `"ai"`: AI가 새로 만든 연습문제. 화면에 'AI 생성 연습문제'로 표시돼요.
  - `"official"`: JLPT 공식 자료. `url`에 실제 주소를 꼭 적어요.
  - `"pdf"`: 내가 가진 PDF에서 옮긴 자료. `label`에 책·파일 이름과 쪽수를 적어요.
    예: `{ "type": "pdf", "label": "내 단어장 PDF p.12" }`
- `review`
  - `"needs-review"`: 뜻·읽기·접속 형태를 아직 사전으로 확인하지 않음. 화면에 '검수 필요'로 표시돼요.
  - `"verified"`: 직접 확인함. '검수 필요' 표시가 사라져요.

출처를 확인할 수 없는 자료에는 `official`이나 `url`을 넣지 마세요.

## 문제 하나의 형식 (모든 영역 공통)

```json
{
  "id": "gq017",
  "kind": "빈칸 채우기",
  "prompt": "本日（　　）営業を終了いたします。",
  "options": ["をもって", "にあって", "をよそに", "ともなると"],
  "answer": 0,
  "explanation": "정답인 이유",
  "wrongReasons": ["", "2번이 틀린 이유", "3번이 틀린 이유", "4번이 틀린 이유"],
  "related": "g001",
  "source": { "type": "ai" },
  "review": "needs-review"
}
```

- `id`는 파일 전체에서 겹치지 않게 지어요. 오답 노트가 이 `id`로 기록을 찾아요.
- `answer`는 0부터 세요(1번 보기 = 0).
- `wrongReasons`는 보기 수와 같은 길이로 쓰고, 정답 자리는 빈 글자(`""`)로 둬요.
- 밑줄을 긋고 싶은 부분은 `[[밑줄]]`처럼 감싸요.
- 독해 문제에는 `evidence`(정답의 근거가 되는 지문 부분)를 넣을 수 있어요.

## 청해 음성 파일

`audio` 폴더를 만들고 mp3 파일을 넣은 뒤, 문제의 `audio` 칸에 경로를 적어요.

```json
"audio": "audio/l001.mp3"
```

`audio`가 `null`이면 브라우저의 일본어 음성 읽기(기계 음성)를 써요. 음성 읽기도 안 되는 기기에서는 '음성 준비 필요'로 표시돼요.
녹음 파일은 저작권을 확인한 뒤에만 넣으세요.

## 주의

- 저작권이 있는 교재의 문제와 해설을 그대로 옮겨 공개 저장소에 올리지 마세요. 이 저장소는 공개(public) 상태예요.
- JSON은 쉼표 하나만 빠져도 사이트 전체가 자료를 못 불러와요. 고친 뒤에는 사이트를 열어 '학습 자료를 불러오지 못했어요' 오류가 없는지 확인하세요.
