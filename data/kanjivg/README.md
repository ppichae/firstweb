# 획순 데이터 (KanjiVG)

이 폴더의 `.svg` 파일은 **KanjiVG** 프로젝트의 획순 데이터를 고치지 않고 그대로 복사한 것입니다.

  - 라이선스 전문은 같은 폴더의 `COPYING` 파일에 있습니다(원본 저장소의 COPYING 파일 그대로).
  - 각 `.svg` 파일 맨 위에도 원본의 저작권·라이선스 안내가 그대로 남아 있습니다.
- 가져온 날: 2026-10-31 (원본 저장소 master 브랜치)
- 가져온 범위: 이 사이트에서 상세 정보를 제공하는 한자 70자(`data/kanji/common.json`의 `strokeRef`)와
  히라가나·가타카나(U+3041–3093, U+30A1–30F6, U+30FC) — 모두 240개 파일
- 파일 이름: 글자의 유니코드 번호(16진수 5자리). 예: 合 → `05408.svg`

사이트는 이 파일에서 획의 모양(path)과 순서만 읽어서 획순 애니메이션과 따라 쓰기 가이드로 보여 줍니다.
