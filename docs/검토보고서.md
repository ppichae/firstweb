# JLPT 학습 사이트 검토 보고서 (9단계, 2026-10-31)

이 문서는 9단계에서 조사·검토한 내용을 정리한 것입니다. **승인이 필요한 항목(외부 서버·유료 서비스·외부 음원 도입)은 실행하지 않았고, 선택지만 정리했습니다.**

---

## 1. JLPT 공식 기준 확인 (2-7)

JLPT 공식 사이트에서 직접 확인한 값만 사이트에 넣었습니다.

| 급수 | 시험 과목과 시간 | 합격 기준 |
|---|---|---|
| N1 | 언어지식(문자·어휘·문법)·독해 110분, 청해 55분 | 180점 중 100점 이상, 세 영역 각 19점 이상 |
| N3 | 언어지식(문자·어휘) 30분, 언어지식(문법)·독해 70분, 청해 40분 | 180점 중 95점 이상, 세 영역 각 19점 이상 |

- 출처: [시험 과목과 시간](https://www.jlpt.jp/e/guideline/testsections.html), [합격 기준](https://www.jlpt.jp/e/guideline/results.html)
- 청해 문제 유형(공식 문제 예시 안내 기준): N1은 과제 이해·포인트 이해·개요 이해·즉시 응답·통합 이해, N3는 과제 이해·포인트 이해·개요 이해·발화 표현·즉시 응답.
  출처: [JLPT 공식 문제 예시](https://www.jlpt.jp/e/samples/sampleindex.html)
- 공식 문제 예시(문제집 PDF·음성)는 무료로 공개되어 있지만 저작물이므로 사이트에 옮기지 않고 **링크만** 걸었습니다(N1·N3 홈의 '시험 구성' 칸).
- JLPT는 급수별 공식 단어·문법·한자 목록을 공개하지 않습니다. 그래서 사이트의 단어·문법·한자에는 공식 급수를 붙이지 않고, '이 방의 학습 목록' 같은 자체 분류임을 표시했습니다.

## 2. 콘텐츠 검수 결과 (2-6)

화면의 검수 상태는 **검수 완료 / 검수 필요 / 자료 준비 중** 세 가지로 통일했습니다. AI가 쓴 내용은 근거로 확인하기 전까지 '검수 필요'로 둡니다.

| 자료 | 확인한 것 | 결과 | 검수 상태 |
|---|---|---|---|
| N1 단어 916 | 표기·읽기를 JMdict와 대조 | 863개 일치, 읽기 불일치 0, 53개는 구절이라 사전에 없음 | 검수 필요(뜻은 AI 작성) |
| N3 단어 733 | 〃 | 702개 일치, 읽기 불일치 0, 31개는 구절 | 검수 필요(뜻은 AI 작성) |
| 기본 단어 44 | 〃 | 44개 모두 일치 | 검수 필요(뜻·예문 AI 작성) |
| 한자 70 | 획수를 KanjiVG와, 음독·훈독·한국 한자음을 KANJIDIC2와 대조 | 모두 일치. 込의 한국 한자음 '입'을 찾아 고침 | 검수 필요(뜻·어원·연상은 미확인) |
| 문법 817(N1 491·N3 306·기본 20) | 빠진 값·중복 기계 검사 | 이상 없음. 참고 목록 문형은 접속·예문이 없음 | 검수 필요 / 자료 준비 중(접속·예문) |

- 대조에 쓴 사전(JMdict, KANJIDIC2 — EDRDG, CC BY-SA 4.0)의 내용은 사이트에 옮기지 않았습니다. 일치 여부만 `data/review/checks.json`과 한자 자료의 `readingsCheck`에 기록했습니다.
- **사람이 직접 확인해야 하는 것**(사이트가 대신 판단할 수 없음): 한국어 뜻, 문법 의미·접속·사용 조건, 예문과 해석, 한자의 뜻(훈)·어원. 이 항목들은 계속 '검수 필요'입니다.
- 참고 목록 단어·문형의 예문은 아직 없습니다('자료 준비 중'). PDF·교재 예문은 옮기지 않았습니다.

## 3. 음성 품질 개선 방안 (2-3) — 비교만, 도입하지 않음

| 방법 | 비용 | 품질 | 라이선스·조건 | 판단 |
|---|---|---|---|---|
| 지금: 브라우저 내장 음성(Web Speech API) | 무료 | 기기마다 다름. 기계음이고 일부 기기는 일본어 음성이 없음 | 없음 | 유지(대체 수단) |
| 직접 녹음한 음성 파일(mp3) | 무료 | 가장 자연스러움 | 녹음한 사람의 동의만 있으면 됨 | **가장 안전한 개선안** |
| VOICEVOX 등 무료 음성 합성 프로그램으로 미리 파일을 만들어 올림 | 무료(내 컴퓨터에서 생성) | 내장 음성보다 자연스러운 편 | 캐릭터마다 이용 규약이 다르고 'VOICEVOX:캐릭터명' 표기가 필요하다는 안내가 있음(공식 규약 원문은 아직 확인하지 않음) | 승인 후 규약 원문 확인 필요 |
| 유료 클라우드 음성 API | 유료(사용량 과금) | 좋음 | 계정·결제 필요 | 사용 금지 원칙에 따라 제외 |
| JLPT 공식 문제 예시 음성 | 무료 공개 | 실제 시험 음성 | 저작물 — 사이트에 올리지 않고 링크만 | 링크만 제공(완료) |

- 이미 반영한 구조: 청해 자료 형식(`data/n3/listening.json`)에 `audio.file`, `audio.source`, `audio.license`를 두었습니다. 녹음 파일을 넣으면 그 파일을, 없으면 기기 음성을 씁니다.
- 참고(제3자 정리 글, 공식 규약 아님): [VOICEVOX 엔진 안내](https://hub.docker.com/r/voicevox/voicevox_engine), [창작 사용 안내 글](https://re-birth-ai.com/voicevox-commercial-use-credit-guide/)

## 4. 학습 기록 동기화 방안 (2-11) — 비교만, 도입하지 않음

| 방법 | 비용 | 보안·개인정보 | 만들기 | 유지보수 | 기록 손실 위험 | 다른 기기 자동 동기화 |
|---|---|---|---|---|---|---|
| ① 지금처럼 서버 없음 | 0원 | 가장 안전(기록이 기기 밖으로 안 나감) | 끝남 | 쉬움 | 브라우저 기록 삭제 시 사라짐 | 안 됨 |
| ② JSON 백업·복원 개선(현재 있음: 전체/N1/N3) | 0원 | 파일을 메신저로 보낼 때만 노출 | 쉬움 | 쉬움 | 백업을 안 하면 위험 | 손으로 파일 주고받기 |
| ③ 무료 서버(예: Supabase 무료 플랜) | 무료 한도 안에서 0원 | 계정·로그인, 데이터가 외부 서버에 저장 | 어려움(로그인·보안 규칙) | 중간 | 낮음(서버 보관) | 됨 |
| ④ Firebase 무료(Spark) 플랜 | 무료 한도 안에서 0원 | ③과 같음 | 어려움 | 중간 | 낮음 | 됨 |
| ⑤ GitHub Gist 등 개인 저장소에 백업 파일 저장 | 0원 | 토큰 관리가 어렵고 실수로 공개될 위험 | 중간 | 중간 | 중간 | 반자동 |

- 무료 한도(제3자 정리 글 기준, 공식 페이지 확인 필요): Supabase 무료 플랜은 프로젝트 2개·DB 500MB이고 **7일 동안 쓰지 않으면 일시 정지**된다고 합니다([정리 글](https://automationatlas.io/answers/supabase-free-tier-limits-2026/)). Firebase Spark는 하루 읽기 5만·쓰기 2만 회 한도이고, 넘으면 다음 날까지 멈춘다고 합니다([Firebase 가격](https://firebase.google.com/pricing/?hl=ko)).
- **추천**: 지금은 ①+②를 유지하고, 두 사람이 서로 다른 휴대폰에서 매일 기록을 보고 싶다면 ③을 검토하는 것이 현실적입니다. ③·④는 이전 지시(외부 백엔드 금지)와 충돌하므로 **승인 전에는 만들지 않습니다.**
- '함께 보기'는 **유지를 추천**합니다. 같은 기기에서는 바로 쓸 수 있고, 다른 기기라면 백업 파일로 볼 수 있으며, 나중에 ③을 도입하면 그대로 자동 동기화 화면이 됩니다.

## 5. 시험 대비 · 모의고사 구조 검토 (2-10)

- N1: 'D-30'(남은 날에 맞춘 학습 계획)과 '모의고사'(실제 시험 구성·시간을 흉내 낸 자체 제작 세트)는 역할이 달라서 **둘 다 유지**합니다.
- N3: '시험 대비'(영역별 연습 + 시간 제한 테스트 + 결과 기록)가 모의고사 역할을 합니다. 실제 시험 구성(언어지식·독해·청해)의 N3 모의고사는 독해·청해 자료가 생기면 같은 화면에 추가할 수 있습니다.
- 두 방 모두 D-Day와 시험일 설정이 따로 저장됩니다. 모든 연습 문제에 '자체 제작 연습 문제, 공식 문제 아님'을 표시하고, 실제 형식은 공식 문제 예시 링크로 안내합니다.

## 6. 아직 남은 일

- 사람이 직접 하는 검수: 단어 뜻, 문법 의미·접속, 예문, 한자 뜻·어원.
- 참고 목록 단어·문형의 예문 작성(새로 작성, 교재 예문 복사 금지).
- N3 독해·청해 자료 작성 또는 이용 허락을 받은 자료 추가.
- 음성 개선·자동 동기화는 위 선택지 중 승인된 방법만 진행.
